# bayes-spm-dynamical-system
Bayesian sparse identification of dynamical systems via model averaging, with uncertainty quantification of interaction structures and functional components.

# Uncertainty-Aware Sparse Identification of Dynamical Systems

Code for the paper:
"Uncertainty-Aware Sparse Identification of Dynamical Systems via Bayesian Model Averaging"

## Overview
This repository implements a Bayesian sparse identification framework for dynamical systems.

The method infers:
- interaction structure
- functional components
- uncertainty via posterior inclusion probabilities

using Bayesian model averaging and parallel tempering.

## Features
- Sparse identification of dynamical systems
- Bayesian model averaging (BMA)
- Uncertainty quantification via inclusion probabilities
- Support for higher-order interactions (pairwise, three-body)
- Experiments on oscillator networks
